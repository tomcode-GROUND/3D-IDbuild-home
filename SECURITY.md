# Security policy

3D IDbuild home runs as a local single-user app. Use its loopback URL and keep OpenAI keys in the **OpenAI key** panel. A browser extension or software with access to your browser or local machine may see the key. The **Analyse plan** action sends the prepared image and conversation to OpenAI.

Report vulnerabilities privately to the repository owner. Once private vulnerability reporting is enabled on GitHub, use **Security → Report a vulnerability**. Include the affected version, impact, and diagnostic details with credentials and private floor plans removed. For suspected credential exposure, revoke the key in the provider dashboard and replace it.
